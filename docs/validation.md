## Контрольные числа учебного примера

Истинные длины заданы генератором, а не реальным прибором. Для предмета: `sqrt(130² + 45² + 60²) = 150,083310... мм`. В учебных показаниях и разметке есть заданные отклонения. По всем доступным принятым кадрам:

- S001: 149,85870103454047 мм;
- S002: 150,16831504608584 мм.

Это контроль работы программы, а не результат проверки метода на реальном объекте. Одна синтетическая пара сессий не доказывает превосходство стратегии.

## Воспроизведение

Основные проверки не требуют установки npm-пакетов:

```text
npm test
python -m unittest discover -s tests -p "test_*.py"
```

Для дополнительной проверки интерфейса установите Playwright в отдельной среде и выполните `node tests/browser.cjs`. `PLAYWRIGHT_MODULE` задаёт путь к пакету; `CHROME_PATH` — путь к локальному браузеру Chrome/Edge. Без `CHROME_PATH` используется браузер Playwright. Тест поднимает локальный сервер на порту 4179 и завершает его после проверки. Файлы испытаний попадут в исключённую папку `playwright-output`; изображения интерфейса — в `docs`.

## Что ещё требует проверки

Реальная съёмка и реальный COLMAP в этой поставке не запускались. Помощник не был проверен на установленном бинарном COLMAP: проверены его разбор формата, выбор настройки и сообщения ошибок. Успех регистрации гладких предметов, достоверность калибровки, неопределённость поз, шум ручной разметки и покрытие интервала должны проверяться лабораторно. Масштабная работа на десятках гигабайт и поведение других браузеров не заявляются.
